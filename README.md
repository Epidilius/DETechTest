# Senior Data Ops and Services Programmer Test

Part A is the game event tracker, written in C++. Part B is a Python script that moves the supplied MongoDB data into PostgreSQL.

- **[Part A](PartA/README.md)** is a client SDK and an ingestion service that checks and stores each event. Game code calls `DataTracker::TrackX`. Read the [README](PartA/README.md) to build and run it, then [DESIGN](PartA/DESIGN.md) for more information on the tracker.
- **[Part B](PartB/README.md)** is a script that reads the player logs from MongoDB, reshapes them into nine PostgreSQL tables, and loads them. Read the [README](PartB/README.md) to run it and see the ER diagram, then [ANSWERS](PartB/ANSWERS.md) for the answers to the questions.

## Run It

Part A requires CMake 3.20 or later and a C++20 compiler.

```
cd PartA
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Part B requires Docker and Python 3.10 or later.

```
cd PartB
docker compose -f "../ExternalAssets/SeniorDataOpsAndServicesProgrammerTest/docker-compose.yml" up -d
pip install -r requirements.txt
python etl.py
python validate.py
python -m unittest
```

Each part's README has the details, including what the output looks like.
